# 0001. Record architecture decisions

- **Status:** Accepted
- **Date:** 2026-11-09

## Decision

We record decisions as ADRs in `docs/adr/`, append-only and numbered. A decision that changes the design updates `docs/superpowers/specs/` and adds an ADR in the same PR.

## Why

The design doc says what chase is; ADRs say why it became that way, so later changes don't silently undo earlier reasoning.
